# .NET Framework Skills

C# skills for Codex and Claude Code targeting classic .NET Framework 4.8 and 4.8.1. Each target has 50 skills across System.Web, WCF, EF6, SQL Server, WinForms, deployment and other enterprise topics.

## Choose a target

| Target | Skills | Project guidance |
|---|---|---|
| .NET Framework 4.8 | [net48](skills/net48/) | [Codex](templates/net48/AGENTS.md) / [Claude](templates/net48/CLAUDE.md) |
| .NET Framework 4.8.1 | [net481](skills/net481/) | [Codex](templates/net481/AGENTS.md) / [Claude](templates/net481/CLAUDE.md) |

Read the project’s effective target and check [Microsoft's Windows requirements](https://learn.microsoft.com/dotnet/framework/get-started/system-requirements) before retargeting. Match the targeting pack and vendor-library support to your build and deployment hosts.

## Quick start

From the source checkout, install selected skills into another project. The installer refuses to overwrite existing folders and can preview its actions.

```powershell
python scripts/install.py --client codex --target net48 --project C:/src/inventory web-api-2-conventions ef6-data-access sql-server-query-review
python scripts/install.py --client claude --target net481 --project C:/src/inventory --all
```

Use `--specialists` to copy project-local agent definitions as well. Add the appropriate project guidance template and adapt the commands to your solution.

From the root of your application, the marketplace clients can also load the published catalog.

```text
claude plugin marketplace add BesartPrebreza/dotnet-framework-skills
claude plugin install dotnet-framework-net48-skills@dotnet-framework-skills
codex plugin marketplace add BesartPrebreza/dotnet-framework-skills
codex plugin add dotnet-framework-net48-skills@dotnet-framework-skills
```

For 4.8.1 select `dotnet-framework-net481-skills`. On Windows, a Git checkout with symlink support is needed for the Codex plugin path. The direct installer reads the canonical skill folders and works with extracted archives.
